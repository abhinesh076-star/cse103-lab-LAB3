## Overview

This repository contains lab work for **LAB 3** of the Computer Fundamentals & Career Pathways (CSE103) course at **K.R. Mangalam University**, Gurugram.

The main purpose of this project is to understand Git, GitHub, version control, remote repositories and Markdown documentation.

## How to Run

Clone the repository:

```bash
git clone https://github.com/abhinesh076-star/cse103-lab-LAB3.git
```

Open the project directory:

```bash
cd cse103-lab-LAB3
```

Run the Python file:

```bash
python3 main.py
```
